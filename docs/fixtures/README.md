# Showcase fixture

Copy only the synthetic notes here into a disposable vault. Open `alpha.md` and `beta.md` side by side in editable Markdown panes; select matching words or phrases to show cross-pane propagation. Inspect every frame for private note titles, account names, tokens and vault paths before sharing.

The [README demo GIF](../assets/workspace-word-highlight.gif) was generated from a real, owner-provided 9-second Obsidian screen recording of the two synthetic notes. The source WebM stays outside this repository; the GIF is cropped to remove empty space, scaled, muted and looped. It does not simulate plugin behavior. Its first frame shows the same selected word highlighted in both panes. This visual example is not a substitute for the manual Android or minimum-version test matrix.

The GIF uses a relative Markdown path from the root README, so GitHub and the Obsidian directory resolve the same committed asset. If replacing it later, use a real capture and review the entire recording for private content before changing the README. An animated GIF is useful for a showcase but is not a directory submission requirement.
